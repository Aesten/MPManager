# MPManager map names, one line per map:  <map id> | <display name> | <aliases> | <short aliases>
# - display name: how chat shows the map ("Switching to Xauna."); may contain spaces.
# - aliases, short aliases: what !setmap and !mode match, separated by spaces, typed without spaces (close
#   misspellings work too). An exact alias always wins, so short ones can be as short as you like ("x", "to").
# - variants: name a map's other versions "base:variant" (xauna:winter, x:w). "xauna" alone picks the map with
#   the plain alias xauna, so give that alias to the version you want as default. Both halves are matched
#   loosely ("xauna:wint"); "xauna:" with an unknown variant lists the variants. A short variant needs its own
#   entry ("to:w" on the winter map), since the "to" before the colon is matched among variant names only.
# Maps without a display name or alias are shown and matched by their id.
# Which maps a mode offers is set in its mode file (scripts/server/modes/), not here.
# Edit here and run scripts/deploy.sh; the server picks up changes without a restart
# (it re-reads ~/bannerlord/maps.txt when it changes).
